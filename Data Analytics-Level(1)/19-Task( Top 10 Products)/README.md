# 📊 Top 10 Products Analysis

## 📌 About the Project

The **Top 10 Products Analysis** project focuses on analyzing product performance using the **Sample Superstore dataset**.

The analysis uses Python and data visualization techniques to study **Sales, Profit, Quantity, Discount, Average Sales, Average Profit, and Profit Margin**. Multiple graphs are created to compare the top-performing sub-categories and identify important business patterns.

> **Note:** The dataset does not contain a `Product Name` column. Therefore, this analysis uses the available **`Sub-Category`** field for product-performance analysis.

---

## 📂 Dataset

The **Sample Superstore dataset** contains sales transaction information such as:

* Ship Mode
* Segment
* Country
* City
* State
* Postal Code
* Region
* Category
* Sub-Category
* Sales
* Quantity
* Discount
* Profit

### Dataset Size

* **Original Records:** 9,994
* **Columns:** 13
* **Duplicate Records:** 17
* **Records After Cleaning:** 9,977
* **Missing Values:** 0

The dataset contains information useful for sales, profit, product, category, regional, and customer-segment analysis.

## 🔍 Key Insights

* Technology is the highest-selling category with approximately **$836K in sales**.
* Furniture generates approximately **$741K in sales**.
* Office Supplies generates approximately **$719K in sales**.
* High sales do not always result in high profit.
* Profitability varies considerably between sub-categories.
* Discount levels can have an important relationship with profitability.
* Comparing Sales, Profit, Quantity, and Profit Margin provides a better understanding of overall performance.
* The analysis highlights both strong-performing and lower-performing sub-categories.

The project data shows total sales of approximately **$2.30 million** and total profit of approximately **$286K** after duplicate removal.
