# 📊 Sales Analysis Excel Project

## 📌 Project Overview

This **Sales Analysis Excel Project** focuses on analyzing customer and sales-related data using **Microsoft Excel**. The project covers data cleaning, preparation, Pivot Tables, charts, and an interactive dashboard to identify customer patterns, sales trends, and useful business insights.

The goal is to transform raw data into a clear and understandable format that can support **data-driven decision-making**.

---

## 📂 Dataset

The project uses an Excel dataset named **`Raw Data.xlsx`**.

The dataset contains customer and demographic information, including:

* ID
* Marital Status
* Gender
* Income
* Number of Children
* Education Level
* Occupation
* Home Ownership
* Number of Cars
* Commute Distance
* Region
* Age
* Age Group
* Bike Purchase Status

## 🔄 Project Workflow

### 1️⃣ Data Cleaning & Preparation

The raw dataset was cleaned and prepared in Excel to make the data suitable for analysis.

Key activities included:

* Reviewing the raw dataset
* Cleaning and preparing the data
* Organizing relevant columns
* Preparing the dataset for Pivot Table analysis

### 2️⃣ Pivot Tables & Charts

Pivot Tables were created to summarize and analyze the dataset.

Charts were then used to convert the summarized data into visual insights and make patterns easier to understand.

### 3️⃣ Interactive Dashboard

An interactive **Sales Analysis Dashboard** was developed in Excel.

The dashboard provides a visual overview of the available sales and customer information and allows users to explore important metrics and trends.
