📊 Simple KPI Tracking Sheet — Microsoft Excel

📌 Project Overview

This project is a simple Excel KPI Tracking Sheet designed to monitor sales-executive performance using a small set of practical Key Performance Indicators (KPIs).

The sheet tracks Total Sales, Target Hit %, Away From Target %, Target Sales, Gap to Target, and Performance Status. It also contains a summary section and a sales comparison chart.

This follows the Excel training workflow in this repository, which covers data cleaning, logical formulas, conditional formatting, aggregation, Pivot Tables, and dashboard-style reporting. The training documentation describes Excel as an end-to-end platform for data analysis and business reporting.

Goal: Turning data into insights, and insights into better decisions.

🎯 Objectives

Track sales performance at employee level.

Compare actual sales with target performance.

Calculate the percentage away from target.

Identify whether an executive has met the target.

Summarize overall KPI performance.

Present performance through a simple chart.

Practice Excel formulas and conditional formatting.

📋 KPIs Used

KPI

Description

Total Sales

Actual sales generated by the sales executive

Target Hit %

Percentage of the target achieved

Away From Target %

Percentage remaining to reach 100% target

Target Sales

Estimated target calculated from actual sales and target-hit percentage

Gap to Target

Difference between target sales and actual sales

Performance Status

Shows whether the target has been met

🧮 Main Excel Formulas

Away From Target %

=1-C5

This calculates the remaining percentage required to reach 100%.

Target Sales

=IF(C5=0,0,B5/C5)

This estimates the target value from actual sales and target-hit percentage.

Gap to Target

=E5-B5

Performance Status

=IF(C5>=1,"Target Met","Below Target")

These formulas use the logical and calculation concepts covered in the Excel training material, including IF-based conditional logic and aggregation functions.
