# 📊 Simple KPI Tracking Sheet — Microsoft Excel

## 📌 Project Overview

This project is a **Simple Excel KPI Tracking Sheet** designed to monitor sales-executive performance using practical **Key Performance Indicators (KPIs)**.

The sheet tracks:

- Total Sales
- Target Hit %
- Away From Target %
- Target Sales
- Gap to Target
- Performance Status

It also includes a **KPI Summary** and a **Sales by Sales Executive** chart for quick performance analysis.

This project is part of a broader Microsoft Excel Data Analyst training workflow covering data cleaning, formulas, conditional formatting, aggregation, Pivot Tables, charts, and business reporting.

> 🎯 **Goal:** Turning data into insights, and insights into better decisions.

---

## 🎯 Objectives

- Track sales performance at employee level.
- Compare actual sales with target performance.
- Calculate the percentage away from target.
- Identify whether an executive has met the target.
- Summarize overall KPI performance.
- Visualize sales performance using charts.
- Practice Excel formulas and conditional formatting.
- Build a simple business reporting solution.

---

## 📋 KPIs Used

| KPI | Description |
|---|---|
| **Total Sales** | Actual sales generated by the sales executive |
| **Target Hit %** | Percentage of the target achieved |
| **Away From Target %** | Percentage remaining to reach 100% target |
| **Target Sales** | Estimated target calculated from actual sales and target-hit percentage |
| **Gap to Target** | Difference between target sales and actual sales |
| **Performance Status** | Shows whether the target has been met |
