# 📊 SuperStore Sales Blinkit Dashboard

## 📌 Project Overview

**SuperStore Sales Blinkit Dashboard** is an interactive **Power BI data analytics and business intelligence project** designed to analyze sales performance, product categories, outlet characteristics, and key business KPIs.

The dashboard transforms raw sales data into meaningful business insights using **Power BI, Power Query, DAX, data modeling, and interactive visualizations**.

---

## 🎯 Project Objectives

The main objectives of the **SuperStore Sales Blinkit Dashboard** are:

* Analyze overall sales performance.
* Track important business KPIs.
* Analyze sales based on product fat content.
* Compare sales across different item categories.
* Analyze outlet performance.
* Identify sales trends by outlet establishment year.
* Compare outlet sizes and locations.
* Understand outlet-type performance.
* Provide interactive filtering for business users.
* Present data in an easy-to-understand dashboard format.

## 🧮 DAX Measures

The project uses DAX measures to calculate important KPIs.

### Total Sales

```DAX
Total Sales = SUM('BlinkIT Grocery Data'[Sales])
```

### Average Sales

```DAX
Avg Sales = AVERAGE('BlinkIT Grocery Data'[Sales])
```

### Number of Items

```DAX
No of Items = COUNTROWS('BlinkIT Grocery Data')
```

### Average Rating

```DAX
Avg Rating = AVERAGE('BlinkIT Grocery Data'[Rating])
```

These measures support the KPI cards and analytical visuals used in the **SuperStore Sales Blinkit Dashboard**.
