# 📊 Superstore Sales Analysis & Sales Forecasting

## 📌 Project Overview

This project focuses on analyzing **Superstore sales data using Microsoft Power BI** and using the **Power BI Forecast tool** to generate sales forecasts from historical data.

The project provides insights into **customer behavior, product performance, regional trends, and future sales patterns**, helping support data-driven business decisions.

---

## 🎯 Objectives

* Analyze Superstore sales data using Power BI.
* Understand customer purchasing behavior.
* Identify top-performing products and categories.
* Analyze regional sales trends.
* Create interactive dashboards for business insights.
* Use the **Power BI Forecast tool** to predict future sales.
* Support business planning and resource allocation through data-driven insights.

---

## 🔮 Forecasting Using Power BI

A key part of this project is the use of the **Power BI Forecast feature**.

Historical sales data is used to identify sales trends and generate forecasts for future periods. These forecasts can help businesses with:

* Future sales planning
* Resource allocation
* Inventory planning
* Business strategy
* Decision-making

The forecasting capability provides an additional perspective beyond historical sales analysis.
