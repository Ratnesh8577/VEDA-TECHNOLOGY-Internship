# 📊 Northwind Database Analysis – SQL and Power BI

## 📌 Project Overview

The **Northwind Database Analysis** is a **SQL and Power BI data analytics and business intelligence project** built to analyze sales, revenue, profitability, customers, employees, shippers, and suppliers.

The project uses **SQL for data analysis and preparation** and **Power BI for interactive dashboard development and visualization**.

The analysis transforms Northwind business data into interactive dashboards that provide insights into:

* 💰 Revenue and profitability
* 👥 Customer behavior and contribution
* 👨‍💼 Employee performance
* 🚚 Shipper performance and delivery
* 🏭 Supplier contribution
* 📦 Quantity and order analysis
* 📅 Monthly and yearly business trends
* 🌍 Country and regional performance

The analysis covers the years **1996, 1997, and 1998**.

---

## 🎯 Project Objectives

The main objectives of this project are to:

1. Analyze sales, revenue, cost, and income using SQL.
2. Prepare and organize business data for analysis.
3. Identify high-performing product categories.
4. Understand customer contribution by country and role.
5. Analyze customer quantity and income trends.
6. Evaluate employee performance.
7. Compare employee performance across regions.
8. Analyze profit and loss ratios.
9. Evaluate shipping costs and delivery time.
10. Identify commonly used shippers and suppliers.
11. Build interactive Power BI dashboards.
12. KPIs and visualizations.
