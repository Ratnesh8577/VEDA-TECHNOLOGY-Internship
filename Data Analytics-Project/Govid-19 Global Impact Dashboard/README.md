# 📈 Confirmation, Recovery & Mortality Rates

The dashboard displays the following percentages.

| KPI | 2020 | 2021 |
|---|---:|---:|
| Confirmation Rate | 7.2% | 6.3% |
| Recovery Rate | 87.7% | 95.2% |
| Mortality Rate | 1.6% | 1.3% |

These are the percentages shown in the screenshot.

## 1. Confirmation Rate

A common test positivity rate formula is:

`Test Positivity Rate = (Positive Tests / Total Tests) × 100`

The actual formula depends on whether the dataset records tests, tested samples, unique people tested, or confirmed cases.

## 2. Recovery Rate

A commonly used cumulative recovery rate is:

`Recovery Rate = (Cumulative Reported Recoveries / Cumulative Confirmed Cases) × 100`

The recovery and confirmed-case measures must use compatible reporting definitions and periods.

## 3. Mortality Rate

If the dashboard uses deaths divided by confirmed cases, the formula is:

`Case Fatality Rate = (Cumulative Reported Deaths / Cumulative Confirmed Cases) × 100`

This represents a reported case-fatality proportion. It is not the same as the infection fatality rate.


A simple positivity measure, where the numerator and denominator are compatible:

```DAX
Confirmation Rate =
DIVIDE(
    [Total Positive Tests],
    [Total Tests],
    BLANK()
)
```
